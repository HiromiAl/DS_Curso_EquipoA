
# DS_Curso_EquipoA

## 📋 Descripción del Repositorio

Este repositorio contiene el material de trabajo colaborativo del **Equipo A** para un curso de **Data Science enfocado en NumPy**. El proyecto acompaña un curso multimedia que cubre desde conceptos fundamentales hasta operaciones avanzadas con arreglos numéricos.

### 📺 Contenido del Curso
El material aborda los siguientes temas:
- **Video 1**: Diferencias entre listas y arrays en Python
- **Video 2**: Uso integrado de listas y arrays
- **Video 3**: Funciones básicas en matrices
- **Video 4**: Operaciones básicas con matrices
- **Video 5**: Números aleatorios
- **Video 6**: Ejes en matrices
- **Video 7**: Funciones estadísticas
- **Video 8**: Álgebra lineal con Python

## 🛠️ Instalación

### 1. Clonar el Repositorio

```bash
git clone https://github.com/HiromiAl/DS_Curso_EquipoA.git
cd DS_Curso_EquipoA
```

### 2. Crear un Entorno Virtual

#### En Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

#### En macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Instalar las Dependencias

```bash
pip install -r requirements.txt
```

---

## 📦 Dependencias

Este proyecto utiliza las siguientes librerías principales:

- **NumPy** (≥1.24.0): Computación numérica y manipulación de arreglos multidimensionales
- **Pandas** (≥2.0.0): Análisis de datos y estructuras tabulares
- **Matplotlib** (≥3.7.0): Visualización gráfica
- **Jupyter** (≥1.0.0): Entorno interactivo para notebooks
- **IPython** (≥6.20.0): Kernel para Jupyter

Para ver todas las versiones especificadas, consulta `requirements.txt`.
